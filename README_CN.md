# star-X

> 面向个人与团队的自托管 AI API 网关。

star-X 用于在你自己掌控的服务器上管理已授权的上游 AI 账号、分组、API Key、路由、额度与用量。

## 最新更新

### 2026-10-12

#### 新增

- 管理端新增简化计费管理，在一页查看模型人民币基准价、售价、来源和待确认规格，并提供不调用模型、不扣费的算费预览。
- 按量 API 使用基准价 × 统一倍率，默认 1.4；授权账号和包月订阅使用参考价 × 分组倍率，每次只应用一条售价规则。

#### 优化

- 管理端收敛为一个「模型管理」入口，日常只保留「模型」「上游」；用户分组、统一计费与高级配置集中到「管理设置」。
- 模型行支持原地配置与试算，开放状态和计费就绪分别展示；分组只管理权限与调度，统一倍率集中维护。
- 用户使用记录、仪表盘和密钥用量展示请求数与真实 token 消耗，记录优先显示，图表按需展开。
- 用户端移除费用明细、成本、售价及倍率，保留余额、充值购买金额与个人额度管理。
- 站内金额统一人民币，美元基准价固定按 6.2 换算；旧余额保留原有购买力，新人民币充值默认支付 ¥100、到账 ¥100。
- 官方维护价表按供应商、地区和规格匹配；第三方单价与合同折扣按需登记，详细采购设置折叠展示。
- 模型目录明确区分 Agent 主模型候选与图片、视频工具接入；客户端导入过滤已识别的生成型号。

#### 修复

- 去除模型页已不生效的旧售价展示，权限保存不再覆盖统一倍率；价格目录不可用时提示待核对，试算保留未保存模型草稿。
- 更新 Go 1.26.9 和相关安全依赖，升级到 SheetJS 官方修复版本；管理端极小费用不再显示成零。
- 用户接口及导出同步移除财务字段，管理员继续查看完整费用；未知采购成本明确标为待核对。
- 采购配置保存检查版本冲突，算费输入变更后旧结果失效，编辑有效期保留原始精度。
- 用户图表悬浮提示隐藏费用并兼容缺失费用字段；生成模型误用对话接口时提前提示正确接入方式。
- 未确认价格的模型或规格在付费调用前拒绝；历史支付退款、旧套餐和已提交媒体任务保持兼容，修正充值与低价用量的换算精度。

## Docker Compose 一键部署

前提：已安装 Docker Desktop（或 Docker Engine）和 Docker Compose v2。

```bash
git clone https://github.com/roby-uo/star-x.git
cd star-x/deploy
cp .env.example .env
# 首次启动前，编辑 .env 并填写必填密钥。
docker compose up -d
docker compose ps
```

浏览器访问 `http://localhost:8080`，用 `.env` 中设置的管理员邮箱和密码登录。

默认镜像为：

```text
ghcr.io/roby-uo/star-x:latest
```

Docker 命名卷会保存应用数据、PostgreSQL 和 Redis 数据；正常更新镜像不会删除它们。升级或调整配置前，请先备份 PostgreSQL。

## 实际调用链路

1. 管理员登录；
2. 创建分组；
3. 添加你有权使用的上游 AI 账号或 API 凭据；
4. 为分组创建 API Key；
5. 客户端通过 star-X 地址调用兼容接口。

只完成部署并不能转发模型请求；还需要配置合法授权的上游账号。

## 安全提醒

- 不要提交 `.env`、数据库备份、API Key、OAuth Token 或 `data/` 目录。
- 首次启动前必须为 `POSTGRES_PASSWORD`、`ADMIN_PASSWORD`、`JWT_SECRET`、`TOTP_ENCRYPTION_KEY` 设置不同的高强度随机值。
- 对外提供服务时，请配置 HTTPS、反向代理和访问控制。
- 请遵守上游服务商的条款、账号规则及适用法律。
