# 管理端计费与用户用量

## 管理入口

管理端「计费管理」集中提供三个页签：

| 页签 | 操作 | 生效范围 |
| --- | --- | --- |
| 模型售价 | 查看登记模型，进入现有模型服务设置售价与规格，选择分组进行算费预览 | 使用现有销售价表，不另建重复售价 |
| 上游成本 | 创建采购方案，关联账号，维护供应商原币成本价表 | 管理端采购成本估算 |
| 充值与换算 | 维护成本汇率、在线充值入账、订阅人民币收款换算 | 三套独立规则 |

日常列表只展示概要。采购价表在编辑面板中展开，同价模型共用一条规则；按型号、分辨率、质量、服务档位或输入用量分别维护差异价。复杂模型路由和批量销售价表仍通过渠道配置管理。

## 采购方式与认证方式

API 密钥和账号授权决定上游连接方式；按量、包月、额度包或混合决定采购费用。两者分别记录。

- 按量：实际用量乘以对应原币单价，再应用协议折扣。
- 包月：记录周期实付，不假设每次调用有准确采购成本。
- 额度包：按实付金额与供应商原币标称额度比例分摊，明确标为估算；未用完、过期及超额费用另核对。
- 混合：按量预览只计算增量费用，固定周期实付单列。

停用、未生效或过期方案不自动参与成本匹配。同账号有多个有效方案时，必须明确选择；缺项或重复成本规则显示待核对。未关联账号的方案可保留为模板。

## 单位与算费预览

文本与图像 token 单价在页面填写为每百万 tokens；普通输入、输出和缓存分别填写。图像 token 是输入／输出的子集，不另重复相加。图像按张、视频按秒或按次，使用对应计价数量。

输入档位用总输入匹配（未缓存输入＋缓存读取＋缓存写入）：下限为0时包含0，其余采用大于下限、小于等于上限。服务档位与规格须命中独立成本规则；缺少对应单价时不能假设免费。

算费预览只读取已保存采购配置和现有销售规则，不向供应商提交请求，不改变用户余额。修改用量后结果失效，需重新计算。预览显示原币成本、可用的人民币折算、分组实际扣费额度及配置版本。

站内美元额度消耗不等于人民币实收。可展开「按充值比例试算收支」，假设额度全部来自指定充值，估算其对应收入和与已配置采购成本的差额。该试算未计手续费、额外赠送、退款、包月分摊或其他运营费用，不代表实际财务利润。

## 汇率、充值与历史余额

- 采购成本汇率：1 USD 对应多少 CNY，只用于成本折算。未配置或未生效时美元成本保留原币，人民币折算为空。
- 在线充值入账：支付金额乘以入账倍率，支付通道决定收款币种。人民币通道例子不代替美元通道的收款规则。
- 订阅收款换算：仅用于人民币通道订阅订单；0 保留原数值直付规则。
- 外部店铺卡密：按兑换码面额入账，需在店铺与兑换码中独立配置，不自动应用在线支付入账倍率。

当前历史钱包、售价和额度仍以 USD 口径保存。人民币钱包迁移必须先根据充值记录、原售卖承诺和余额权益形成兑换／补偿方案，再统一迁移。上述配置不执行历史余额转换。

采购成本目前用于管理员预览。供应商自动对账、历史调用采购成本快照和人民币钱包迁移不属于本次能力，不能将账号用量估算或预览金额当作供应商已确认账单。

## 用户端展示与接口

用户只需查看可用模型、调用结果、请求次数、真实 token 和媒体用量。使用记录、密钥用量、仪表盘、图表、CSV、公开密钥查询及模型提示不展示成本、基础售价、倍率或费用明细。余额、购买与充值实付、自设安全额度仍可查看。

用户接口使用专用响应字段；管理员接口保留完整财务信息。视频校验返回不透明的 `version`，提交时仍用 `X-Video-Quote` 校验配置；金额快照由服务器保存，用于后续结算。

兼容路径 `/v1/sub2api/billing` 的版本2响应只包含可见性元数据，不返回费率。旧版上游费率探测收到该响应时标记未读取，不能猜测费率为1。
