# star-X 更新记录

### 2026-09-30

#### 新增

- MiniMax 视频接入扩展到 H3-Max，支持 480P／768P、5–15 秒；H3 继续支持 768P／2K、4–15 秒，两个模型均支持文生视频、首帧图生视频与首尾帧视频。
- 管理员可分别维护 H3 和 H3-Max 的开放规格、每秒基础售价及分组权限；用户可在统一模型详情中查看 API 示例并在线测试。
- MiniMax 上游账号可一键添加 H3 / H3-Max，语言模型预设补充 M3、M2.7、M2.5、M2.1、M2 系列；实际可用模型以账号授权为准。

#### 优化

- 管理端统一模型服务目录，按文本、图像、视频管理；在模型详情完成规格、基础售价和分组开放，分组倍率与视频任务账务有独立入口。
- 应用模型配置前明确确认影响范围；修改已发布模型保持开放状态，暂停独立操作，共享价格中的其他模型不受影响。
- 用户端改为模型卡片目录，同协议模型跨分组合并；详情统一分组、调用密钥、API 示例和在线测试。
- 按 API 中转站定位移除用户端价格与限制面板和“我的视频任务”入口；视频应用通过任务编号查询，后台记录与账务继续保留。
- 视频在线测试在当前窗口显示任务状态和结果；提交不确定时保留编号并阻止重复生成。打开详情不会自动产生调用，测试前需确认消耗账户额度。

#### 修复

- H3 与 H3-Max 分别读取服务配置及分辨率价格，避免两个模型相互套用规格或费用。
- 视频测试同时遵守模型能力、分组和密钥权限，H3-Max 不再出现 H3 的 2K／4 秒选项，未适配型号不会被当作已支持模型开放。
- MiniMax 官方 M3 的优先处理按对应上下文档位基础价格的 1.5 倍计费，再应用现有分组倍率；管理员过滤优先处理参数后按实际请求计费。

### 2026-09-29

#### 新增

- 接入 MiniMax-H3 视频任务提交与结果查询，支持文生视频和首尾帧图生视频；配置 MiniMax 上游账号后即可通过 API Key 调用。
- 模型服务支持草稿、发布、暂停以及分组开放规则；H3 可设置分辨率、时长、生成方式与每秒售价，图片可限制尺寸和单次数量。
- 用户端新增规格与价格详情、图片生成、H3 报价与视频生成、视频任务历史；分组倍率继续生效。
- API 密钥可进一步限制模型、视频分辨率与时长；启用模型白名单后通过 HTTP 接口调用。
- 视频提交增加余额预占、幂等提交与后台状态恢复；管理员可核对不确定任务、释放未受理任务额度，并为失败的余额付费任务退款。

#### 修复

- 模型配置读取失败时保持拒绝状态，避免短暂丢失权限限制。
- 修复管理端按 Images 类型筛选时显示为空的问题，并移除不需要的 Audio 类型筛选。
- 用户端模型管理现在按可访问分组展示已配置模型，无需先创建“对外服务”。
- MiniMax 账号可直接添加 H3 视频模型，并提示视频模型可能不出现在上游同步列表中。

### 2026-09-23

#### 优化

- OpenAI 模型选项加入 GPT-6 Astra、Sol、Luna；实际能否使用仍由上游账号权限决定。
- 上游模型同步失败时展示具体错误原因，便于区分账号、网络和上游服务问题。

#### 修复

- 修复 OpenAI OAuth 账号无法同步上游模型的问题，现可读取该账号的 Codex 模型清单并添加到白名单。

### 2026-09-20

#### 优化

- 管理后台将“账号管理”统一为“API管理”，避免导航与页面标题表达不一致。
- 默认品牌名称与登录页说明统一为“star-X API算力中转站”；已有数据库仍保存旧默认文案时，前端会自动兼容显示新名称，自定义品牌不受影响。
- 首页 Hero 区以大幅 star-X 标识和“API算力中转站”组成完整品牌标题，移除旧的“你的私人 AI API 网关”文案。
- 后台侧栏改用清晰大 Logo 与“star-X / API算力中转站”双行文字布局，减少长名称对 Logo 清晰度的挤压。
- 后台侧栏品牌区进一步优化为紧凑品牌条：Logo 保持清晰可辨，`star-X` 与版本号同行，副标题独立成行，并以轻量分隔线自然衔接导航。

### 2026-09-17

#### 新增

- 自动调动区域新增“调度时间”选择，可在 0.5、1、1.5、2、2.5、3、3.5、4 小时之间切换。
- 调度时间会持久保存；修改后按当前服役轮次的开始时间重新计算，若新时间已经到期则立即切换到下一个具备额度的 OpenAI OAuth 账号。
