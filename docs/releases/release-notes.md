# star-X 更新记录

### 2026-09-20

#### 优化

- 管理后台将“账号管理”统一为“API管理”，避免导航与页面标题表达不一致。
- 默认品牌名称与登录页说明统一为“star-X API算力中转站”；已有数据库仍保存旧默认文案时，前端会自动兼容显示新名称，自定义品牌不受影响。
- 首页 Hero 区以大幅 star-X 标识和“API算力中转站”组成完整品牌标题，移除旧的“你的私人 AI API 网关”文案。

### 2026-09-17

#### 新增

- 自动调动区域新增“调度时间”选择，可在 0.5、1、1.5、2、2.5、3、3.5、4 小时之间切换。
- 调度时间会持久保存；修改后按当前服役轮次的开始时间重新计算，若新时间已经到期则立即切换到下一个具备额度的 OpenAI OAuth 账号。
